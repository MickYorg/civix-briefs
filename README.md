# CiViX briefs

Listening briefs about building [CiViX](https://mycivix.com), a civic engagement app: daily (except Monday), weekly (Monday) and quarterly, written each morning by a scheduled Claude routine from the project's public commit history and test results.

Each brief uses a rotating creative frame (a ship's log, a debate, a letter from 2030…). Facts about the project are real; voices, characters and future scenes are imagined and labeled as such.

Files: `briefs/YYYY-MM-DD-<daily|weekly|quarterly>-<frame>.txt`, plain text written for text-to-speech.
